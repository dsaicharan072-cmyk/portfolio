## 💻 Local Development

To run this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/dsaicharan072-cmyk/portfolio.git
   cd portfolio
   ```

2. Open `index.html` in your favorite browser or start a local HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 3000
   ```
3. Open `http://localhost:3000` in your browser.
